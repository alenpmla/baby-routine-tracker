# Phase 4 addendum — Sleeping now indicator navigates to Sleep tab

## Goal

Tapping the "Sleeping now — …" indicator on the dashboard takes you to the Sleep tab.

## Acceptance criteria

- While a sleep is running, the dashboard "Sleeping now" pill is a clickable button.
- Clicking it opens the Sleep tab (where the timer can be stopped/edited).
- Keyboard/touch accessible (a real `<button>`).
- Build + tests pass.
