# Phase 4 addendum — Dashboard cards/events navigate to their screens

## Goal

Tapping a dashboard summary card or a timeline entry takes you to the matching screen.

## Acceptance criteria

- "Sleep today" -> Sleep tab, "Feeds today" -> Feeding tab, "Diapers today" -> Diaper tab.
- Tapping a timeline event (slept / feed / diaper) opens the matching screen.
- Keyboard/touch accessible (buttons).
- Build + tests pass.
